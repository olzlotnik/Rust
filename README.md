Злотник Ольга Андреевна  
№1 "Знакомство с языком программирования Rust"  
Примеры из глав 1–5.3 были проверены через создание проектов с помощью cargo new, замену кода в src/main.rs и запуск cargo run.  
Были разобраны основы языка: переменные, функции, управление потоком, владение и ссылки, а также структуры и методы на примере Rectangle.
